I build digital tools and experiences where software meets music, design, and writing. My work moves between practical web applications and creative experiments.

### Selected work

- **[ShenoBin](https://github.com/soroush-zendedel/shenobin)** — A browser-based workspace for music theory, composition, and sound experiments.
- **[Tara](https://github.com/soroush-zendedel/tara)** — A visual way to explore music theory, scales, chords, and instrument fretboards.
- **[Khater](https://github.com/soroush-zendedel/khater)** — A Persian type-design workbook for glyphs, metrics, kerning, and font-making practice.
- **[Notella](https://github.com/soroush-zendedel/notella)** — A Python note-taking app with command-line and web interfaces.
- **[Sabte Ahval](https://github.com/soroush-zendedel/personal-blog)** — A personal notebook for essays, reflections, poetry, and stories.
- **[Portfolio](https://github.com/soroush-zendedel/soroush-zendedel.github.io)** — My bilingual portfolio and collection of digital projects.
